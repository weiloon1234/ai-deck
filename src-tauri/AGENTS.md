# Native Rust guidance

Inherits [root guidance](../AGENTS.md). Rust owns durable state, cloud operations, validation and local processes.

- Keep `commands.rs` a thin Tauri boundary. Put domain behavior in the existing focused `AppCore` services. Register new commands in `lib.rs` and export shared types through `examples/export_contracts.rs` when needed.
- Reuse `CloudProvider`, `RuntimeApi`, `CredentialStore`, `HuggingFaceApi` and `ModelAnalyzer` boundaries. Provider payload construction and ownership checks belong to the adapter; bounded HTTP utilities live in `http_client.rs`. Extend existing clients and fixtures rather than creating parallel cloud or credential implementations.
- Runpod remains the only paid deployment adapter. Both providers are selectable in Setup, but GPUtw only has a read-only key check and an authoritative creation gate. Route deployments, imported-model price refresh and endpoints by saved provider identity through `CloudProviders`; never by the current Setup selection. Key replacement/removal is guarded against active deployments of that key's provider. Old records default to Runpod. Read [provider integration](../docs/provider-integration.md) before adding another. Require documented creation correlation, provider-bound saved records/quotes/endpoints/credentials, and verified cleanup; never infer app ownership from account access alone. Preserve the Runpod default for existing state.
- Write state through `StateStore::update`. Preserve atomic writes, private permissions, the exclusive app lock and failure behavior that leaves existing state intact. Add default-compatible fields or an explicit non-destructive migration; test old saved records.
- Validate persisted identity invariants before startup normalization writes. Damaged but decodable state must return a sanitized recovery error, preserve the original bytes and never reach unchecked identifier slicing in provisioning.
- Keep network/process work outside the state mutex. Respect the deployment operations lock and separate model-import lock. Analysis must remain cancellable without blocking Finish; timeouts and quit must clean up owned processes.
- Preserve durable creation intent and reconciliation of uncertain provider responses. Keep the original sanitized provider error in `Deployment.creation_error` independently of stage messages; retain it across reconciliation, Finish, restart and explicit absence resolution, and include it in the diagnostics allowlist. Runpod creation diagnostics retain HTTP status and only fixed labels for recognized parameter references from bounded error envelopes; never echo raw messages, values, environment or credentials. A parameter reference is not proof of a specific cause or provider absence. Do not retry paid creation blindly. Only modify/delete owned resources and never treat a missing response or stopped process as verified Pod deletion.
- Paid creation still requires hourly/total-budget limits, opt-in and confirmation. New deadlines derive from remaining budget and rate through the shared budget helper; retain earlier saved deadlines and only shorten them. Ignore the legacy maximum-lifetime field. CLI launch/resume permit combinations without a candidate acknowledgement while still recording exact compatibility status and preserving readiness, capacity, binding and isolation checks.
- Runtime checks must verify authentication rejection, model identity and inference before Ready/Enable. Compatibility evidence remains bound to the full profile/runtime/launcher fingerprint, GPU and exact CLI version.
- Credentials stay behind `CredentialStore`. Diagnostics and surfaced errors use approved sanitized fields, not raw upstream errors, environment dumps or child-process logs. GPUtw requests require an identifiable app/version `User-Agent` and JSON `Accept` header; keep credentials in bearer headers and retain bounded, redirect-free transport.
- Personal macOS packaging uses the configured ad-hoc signing identity `-`; verify the bundle seal after rebuilding. This is not Developer ID signing or notarization. Do not use working signing credentials or contact Apple's notarization service implicitly.
- CLI adapters own isolated coding-session configuration. The normal-subscription analyzer is a separate restricted path; keep its authorization, bounded schema, timeout/cancellation and untrusted-metadata handling intact.
- Experimental imported-model settings live in the existing model record, separately from AI analysis. Save through the model-import lock and atomic StateStore update, check the expected profile version, refresh hardware by saved provider and reuse native profile/quote construction. Reanalysis and quote refresh preserve manual settings. Missing local config blocks automatic profiles, but explicit trials may defer retrieval to the pinned runtime; preserve unknown metadata and gated/private access, including the pre-creation secret requirement. Never infer passing evidence, accept arbitrary runtime commands/images or change existing deployment/session snapshots. Paid creation must match the reviewed profile fingerprint.
- Use explicit command arguments and controlled environments, not shell interpolation. Track and stop only owned process trees. Session resume must wait for prior process cleanup.
- Keep Hub metadata reads bounded and tied to validated Hugging Face URLs and immutable revisions. AI output cannot choose executable code, arbitrary URLs, container images or credential routes. Prices are calculated from provider quotes, never supplied by the analyzer.
- External links use the private validator in `commands.rs`. Allow only the specific provider pages the UI needs; test validation without launching the system browser. Preserve HTTPS, host, path and credential/query restrictions.

Read [native test guidance](tests/AGENTS.md) and reuse `tests/support` with disposable state and fake providers/credentials. Adapter edits also follow [CLI guidance](src/cli_adapters/AGENTS.md). Add focused regressions for lifecycle, storage, metadata and process changes. Run Cargo formatting/lints and applicable tests; for exported types also regenerate contracts and build the frontend. Never weaken production invariants to satisfy a fixture.
